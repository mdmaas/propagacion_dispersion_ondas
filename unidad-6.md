# Unidad 6: Ecuaciones integrales de superficies/curvas

Para el caso de curvas suaves usamos cuadratura de Chebyshev con un cambio de variables para resolver la singularidad. Para curvas singulares, usamos métodos de clústering y también estudiaremos un método de [Cuadratura Gaussiana Generalizada](pdf/pde_polygonal_domains.pdf).
